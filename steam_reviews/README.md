# Отзывы Steam: Quarantine Zone: The Last Check

Два скрипта, только стандартная библиотека Python 3 (для `.xlsx` нужен `openpyxl`, без него будет только CSV).

## 1. Скачать отзывы

```bash
python3 fetch_reviews.py            # сам находит app id игры через поиск Steam
python3 fetch_reviews.py --appid N  # если поиск ошибся
```

Результат в `data/`:

| файл | что внутри |
|---|---|
| `reviews.csv` / `reviews.xlsx` | все отзывы на всех языках: id, дата создания и правки (UTC), язык, 👍/👎, часы в игре, голоса «полезно», текст, **`fetched_at_utc`** — когда строка была скачана |
| `state.json` | app id, **дата самого нового сохранённого отзыва** (`newest_created_utc`) и время последнего запуска |

**Повторный запуск докачивает только новое**: скрипт идёт от новых отзывов к старым и
останавливается на первом, который не новее `newest_timestamp_created` из `state.json`.
Ещё он обновляет отзывы, которые авторы правили после прошлого запуска.
Дубликатов нет (ключ `recommendationid`). `--full` скачивает всё заново.

## 2. Тир-лист просьб

```bash
python3 analyze_requests.py                                  # по всем отзывам
python3 analyze_requests.py --since "2026-11-01 00:00:00"   # только по новым
```

Как работает: текст режется на предложения, из них берутся те, где есть маркер просьбы
(«добавьте», «не хватает», «хотелось бы», «please add», «wish», «needs», и аналоги на de/es/pt/fr/pl/tr/zh).
Эти предложения раскладываются по темам (`THEMES` в скрипте). Один отзыв засчитывается
в теме один раз. Тир — доля всех отзывов с этой просьбой: S ≥ 8%, A ≥ 4%, B ≥ 2%, C ≥ 1%, D < 1%.

Результат в `data/`: `requests_tierlist.md` (тир-лист с цитатами),
`requests_tierlist.csv` и `requests_sentences.csv` (все найденные просьбы).
Раздел *Uncategorized* показывает просьбы без темы: по ним стоит дописать новые темы в `THEMES`.
