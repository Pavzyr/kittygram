## Открытые вопросы, которые остались
- Текст надписи над победителем (не «КЛЮЧ!»).
- Цены, шансы рулетки; бесплатная ежедневная крутка — да/нет.
- Скетч кота-маскота (Чеширский по духу, дизайн свой).
- Доступны ли чаты Roblox игрокам из РФ; DevEx (вывод Robux) из РФ — изучить.
- Стратегия каналов (шортсы-first / влоги / сообщество мода) — на паузе.

## Настройка на компьютере (Windows или Mac)
1. Установить **Git** и **Roblox Studio**.
2. Склонировать репозиторий и перейти на ветку:
   ```
   git clone https://github.com/Pavzyr/kittygram
   cd kittygram
   git checkout claude/first-1000-computer-games-bzom5e
   ```
3. Поставить скилл brainstorming:
   ```
   npx claude-code-templates@latest --skill development/brainstorming
   ```
4. Подключить официальный MCP-сервер Roblox Studio (репозиторий Roblox `studio-rust-mcp-server` на GitHub, следовать его README) — локальная сессия Claude поможет.
5. Запустить `claude` в папке и написать первое сообщение:
   > Прочитай docs/brainstorm/HANDOFF.md и docs/brainstorm/BACKLOG.md. Продолжаем по скиллу brainstorming: следующий шаг — дизайн-документ MVP для Open Sesame.
